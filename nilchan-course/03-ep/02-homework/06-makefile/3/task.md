# Задание на разработку программы на Golang

Создайте на Golang программу, которая при запуске:

1. Создаёт подключение к базе данных PostgreSQL. Строку подключения к базе данных программа должна брать из переменной окружения `"CONN_STRING"`.
2. Создаёт в базе данных (если ещё не создана) таблицу `users`, у каждого пользователя должны быть: обязательный `ID`, обязательный `FullName`, опциональный `PhoneNumber`.
3. Получает переменную окружения `"NEW_USER"`.
4. Если в переменной окружения `"NEW_USER"` лежит строковое значение `"YES"`, то программа начинает читать из пользовательского ввода следующие значения: имя (`FullName`) и номер телефона (`PhoneNumber`). И создаёт в таблице `users` нового пользователя с соответствующими именем и номером телефона, после чего завершает своё выполнение.
5. Если в переменной окружения `"NEW_USER"` лежит `"NO"`, тогда программа выводит всех пользователей из таблицы `users` на экран, после чего завершает своё выполнение.
6. Если в переменной окружения `"NEW_USER"` лежит что-то кроме `"YES"` или `"NO"`, либо если переменная окружения `"NEW_USER"` вообще не задана, то это считается ошибкой, и нужно вывести соответствующее сообщение на экран.

# Дополнительные требования

- Создайте `.env` файл, в котором будет описана строка подключения к базе данных `"CONN_STRING"`.
- Добавьте (если вы работаете в рамках git-репозитория) `.env` файл в `.gitignore`.
- Опишите `Makefile`, который при выполнении каких-либо таргетов будет предварительно получать и выставлять все переменные окружения из `.env` файла.
- Опишите `Makefile`-таргет, который будет:
  1. Выставлять переменную окружения `"NEW_USER"`.
  2. Запускать описанную на Golang программу.

# Тестирование

Протестируйте описанный `Makefile`-таргет и вашу программу при различных значениях `CONN_STRING` и `NEW_USER`. При тестировании держите рядом pgAdmin, чтобы проверять, действительно ли ваша программа работает с базой данных так, как вы этого ожидаете:
- создаётся ли таблица `users`,
- кладутся ли в эту таблицу новые записи,
- корректно ли из этой таблицы достаются сохранённые ранее записи.
